Zmena

SQL schema evolution from Git history

Zmena understands how a SQL schema evolves in Git and turns DDL diffs into semantically meaningful SQL migrations

Problem

Writing SQL migrations by hand... again?

  • Multiple environments require consistent schema changes
  • Multiple releases need versioned migration scripts
  • Endless ALTER TABLE statements written manually

Solution

The tool requires no custom migration language.

  • Treats files in Git as the source of truth
  • Parses DDL scripts from commit history
  • Detects column correspondence
  • Generates dialect-specific SQL migrations

Building Blocks

Workflow

Combines pipelines into a processing sequence. Orchestrates the execution order and manages data flow between stages.

Pipeline

Self-contained processing unit with specific input, output, and responsibility. Performs one stage of analysis.

Handoff

Converts outbound messages from one pipeline into inbound messages for the next. Eliminates the gap between pipeline outputs and inputs.

Message

Data exchanged between pipelines. Carries the results of one stage to be consumed by the next.

Orchestration

Pipelines combine into different chains orchestrated by workflows. The green pipelines form a strict chain (DC → SI → SE → MF) that cannot have gaps in the middle but may be shortened at either end. Yellow and blue pipelines can connect to green pipelines at any point in the chain depending on the task.
